MyPlanner

MyPlanner is a mobile task management application designed to help users organize daily tasks, set priorities, and manage their schedules efficiently. I designed the application in Figma with a focus on simple navigation, clear layouts, consistent typography, colors, and an easy-to-use interface. I then developed the application using Android Studio, Java, and XML based on the Figma design.
